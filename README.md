# posto-de-saude
## Projetos de Análise de Dados — Posto de Saúde

Este repositório reúne cinco projetos desenvolvidos durante o Bootcamp de Análise de Dados da Generation Brasil.

O tema escolhido foi **Posto de Saúde**, com o objetivo de trabalhar com dados fictícios relacionados à rotina de atendimentos em uma unidade de saúde.

A proposta é desenvolver conhecimentos em análise de dados, organização de informações e construção de projetos práticos, utilizando situações inspiradas na área da saúde.

## Objetivo

Explorar dados relacionados aos atendimentos de um posto de saúde, buscando organizar informações e desenvolver análises que possam ajudar a compreender melhor o funcionamento dos serviços.

## Projetos

| Projeto | Descrição | Status |
|---|---|---|
| **Projeto 01 — Base de Dados** | Criação e organização das tabelas de pacientes e atendimentos. | Concluído |
| **Projeto 02 — Estatística com Python** | Análise estatística dos dados, com foco no tempo de espera dos pacientes. | Em desenvolvimento |
| **Projeto 03 — Relatório Dinâmico** | Construção de relatório com tabelas dinâmicas, gráficos e fórmulas no Excel. | Não iniciado |
| **Projeto 04 — SQL e Visualização** | Consultas SQL, modelo relacional e visualização de dados. | Não iniciado |
| **Projeto 05 — Big Data com Python** | Aplicação de conceitos de Big Data e Machine Learning ao tema. | Não iniciado |

## Tecnologias e ferramentas

- **Python:** manipulação e análise de dados.
- **Pandas e NumPy:** organização e cálculos estatísticos.
- **Matplotlib e Seaborn:** visualização de dados.
- **Google Colab:** desenvolvimento dos notebooks Python.
- **Google Sheets:** organização e armazenamento das bases.
- **Excel:** construção de relatórios dinâmicos.
- **SQL:** consultas e manipulação de bancos de dados relacionais.
- **Git e GitHub:** versionamento e documentação dos projetos.

## Observação

Todos os dados utilizados nos projetos são fictícios e têm finalidade exclusivamente educacional.
