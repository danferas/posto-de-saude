# Projeto 02 — Estatística com Python

## Tema: Posto de Saúde

Este é o segundo projeto de uma sequência de cinco projetos com o tema Posto de Saúde, desenvolvidos durante o Bootcamp de Análise de Dados da Generation Brasil.

Nesta etapa, o foco é utilizar estatística descritiva para analisar os dados de pacientes e atendimentos, identificar padrões e transformar os resultados em informações relevantes.

## Objetivo

Analisar os dados de atendimentos por meio de medidas estatísticas, tendo como questão principal:

**Qual é o tempo médio de espera dos pacientes para serem atendidos no posto de saúde?**

A partir dessa pergunta, a análise busca compreender o comportamento dos tempos de espera, explorar sua distribuição e comparar diferentes medidas estatísticas para interpretar os resultados.

## Base de dados

Serão utilizadas as tabelas desenvolvidas no Projeto 01:

- **Pacientes:** informações fictícias sobre os pacientes.
- **Atendimentos:** informações sobre os atendimentos realizados, incluindo nível de triagem, sintomas e tempo de espera.

## Análises desenvolvidas

- Cálculo de medidas de tendência central: média, mediana e moda.
- Cálculo de medidas de dispersão: variância, desvio padrão, amplitude e quartis.
- Comparação entre média e mediana para compreender o comportamento dos tempos de espera.
- Análise da distribuição dos dados.
- Identificação e avaliação de possíveis valores discrepantes (outliers).
- Construção de gráficos para facilitar a interpretação dos resultados.

## Ferramentas utilizadas

- Python
- Google Colab / Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Entrega

Relatório estatístico com interpretação dos resultados e recomendação de decisão baseada nos dados analisados, utilizando gráficos como recurso complementar.

## Cuidados com os dados

Todos os dados utilizados são fictícios e têm finalidade exclusivamente educacional.
